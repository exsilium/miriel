Citation format

Write each citation inline, immediately after the claim it supports, in exactly this form: `[Vol 1, p. 214]`, using the book label and printed page number from the document's title. Whenever possible add a short verbatim quote (under 20 words) from that document after a colon: `[Vol 1, p. 214: "exact words from the page"]`. One marker per claim. Do not group several pages in one marker, do not use footnotes, and do not invent page numbers that are not in a document title.
